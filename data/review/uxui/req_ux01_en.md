[EN-UX01] 한국인을 위한 영어 회화 학습 앱 「영어 유니버스」의 아이패드 UX/UI **글 시안 1개**를 부탁합니다(그림은 다음 요청에서 따로). 첨부 1 = 통과된 고정 캐릭터 시트(점토 톤 6명, 뉴욕 브루클린 친구들), 첨부 2 = 자매 앱(일본어)에서 채택한 시안 02(만화책 읽기형), 첨부 3~5 = 지금 이 앱의 아이패드 화면(홈 / 회화 리더 / 나).

## 앱 소개(지금 상태)
- 한국 학습자는 영어를 "읽으면 아는데 들리지 않고, 말하면 딱딱하다". 영어는 라틴 문자라 글자 팝업은 없고, 대신 **소리와 말투**가 핵심이다.
- 이 언어만의 강점: ① **강세·리듬** — 강세 받는 낱말만 또렷하고 나머지는 약해진다 ② **이어 말하기·약해지는 소리** — want to → 워너, did you → 디쥬, get it → 게릿 ③ **구동사·덩어리 표현** — get up / figure out / come on ④ **공손도의 층** — Can you… / Could you… / Would you mind… 같은 부탁의 온도 차.
- 탭은 배우기 · 복습 · 탐색 · 나. 배우기 = 인사 → 오늘의 학습 → 기초(소리 배우기, 준비중) → 회화(주제별 회화) → 단어(절벽 단어 R1~R4, 준비중).
- 아이패드(가로 720 이상)는 왼쪽 레일 + 왼쪽 칸(탭 목록) | 오른쪽 칸(고른 화면). 회화 리더는 시안 02 그대로: 장면 컷(말풍선) + 현재 문장 캡션 + 대화 스크립트 + 하단 재생·속도·자막 칩(English 고정 / 발음 / 독음 / 한국어). 첨부 4 가 지금 화면(회화 데이터가 아직 없어 자리표시 문장).
- 회화 한 줄 예(형식만): A 「Wanna grab a coffee?」 — 독음 「워너 그랩 어 커피?」 — 한국어 「커피 한잔할래?」.

## 지킬 것
- **기본 구조는 첨부 2(시안 02)를 그대로 둔다**: 장면 컷이 주인공, 좌 스크립트·우 컷, 하단 컨트롤, 홈의 「오늘의 컷 / 이어서 읽기」, 나 탭의 성과. 그 위에 **영어 강점이 드러나는 칸 1~2개만** 제안해 주세요(예: 리더 캡션에서 강세 낱말 굵게 + 약해지는 부분 옅게, 이어지는 소리 표시 / 덩어리를 누르면 표현 카드 / 같은 부탁의 공손도 3단 비교 — 이 중 고르거나 더 나은 것).
- 톤: 흰 바탕 · 남색 #0A2540 글자 · 영어 강조색 인디고 #4F46E5 → #8B85FF 그라데이션(버튼·현재 턴·성과) · 인디고 #635BFF(선택·보조) · 선 #E6EBF1 · 보조 글자 #6B7C93 · 홈 상단 파스텔 메시(복숭아·분홍·라벤더·하늘 번진 원). 8pt 그리드.
- 인물·장면은 첨부 1 의 캐릭터로(브루클린의 카페·거리·셰어하우스·농구장).
- 성과 원칙: **세는 것** = 편 완주·그림 카드 맞음·핵심 표현 / **안 세는 것** = 앱 오픈·스트릭·포인트·순위.

## 글 시안 1개(한국어)
1. 회화 리더(아이패드 가로)에 더할 영어 강점 칸 1~2개 — 무엇을, 어디에, 누르면 무엇이.
2. 배우기 탭 왼쪽 칸 구성(오늘의 컷 / 이어서 읽기, 기초 「소리 배우기」를 어떻게 보여 줄지, 준비중 메뉴는 감추거나 접기).
3. 나 탭(성과) 한 화면.
각 항목에 아이패드 가로 기준 **ASCII 레이아웃 1개씩**, 글자 크기·간격·색 토큰. 그림은 이번에는 그리지 마세요.
